## About this Release

This is the 1.1.0 release of ADC Service product.

## What's New

 - Sample read example for daisy chain combination.
 - API names of adi_adc_EnableDatapathConfig and adi_adc_EnableClockOut changed to adi_adc_SetDatapathConfig and adi_adc_SetClockOut respectively.

## Minimum Prerequisites

To run the provided examples, use one of the supported evaluation platforms (with the listed revisions or later):

| Supported Hardware | Board Rev |
| --- | --- |
| EVAL-ADEMA127KTZ | REVB|
| EVAL-ADE9113EBZ | REVA|
